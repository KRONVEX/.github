# Security Policy

**NOVALIS** builds cross-platform applications, market intelligence platforms, and mission-critical AI systems. Security and reliability are foundational to everything we ship.

## Supported Versions

Security patches are actively maintained for the latest release and `main` branch of each active repository under the [N-O-V-A-L-I-S](https://github.com/N-O-V-A-L-I-S) organization.

| Version | Supported |
| ------- | --------- |
| Latest release / `main` | Yes |
| Older releases | Case-by-case for critical vulnerabilities |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues or pull requests.**

Instead, please report them responsibly via one of the following private channels:

1. **GitHub Private Vulnerability Reporting:** Use the **"Report a vulnerability"** button in the **Security** tab of the affected repository.
2. **Direct Security Contact:** Email **khalidnaami66@gmail.com** with the subject line `[SECURITY] <Repository Name> - <Brief Summary>`.

### What to Include

- Affected repository, branch/commit hash, or version.
- Clear description of the vulnerability and potential impact.
- Minimal step-by-step reproduction instructions or proof of concept.
- Any suggested remediation or mitigation, if known.

## Response Timeline

- **Acknowledgment:** Within 48 hours of receipt.
- **Initial Triage & Severity Assessment:** Within 5 business days.
- **Remediation & Coordinated Disclosure:** Prioritized based on severity (Critical/High issues are fast-tracked).

We deeply appreciate responsible disclosure and will credit researchers who help strengthen the security of NOVALIS systems.
